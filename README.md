# API-Leitura-integrada

No momento o projeto não tem um readme adequado, pois está na fase de construção do MVP, por isso peço desculpas.

## Objetivo
O objetivo desse projeto é estabelecer uma integração entre dispositivos para facilidade de leitura.

Essa parte do sistema será a API que possibilitará a integração de diferentes plataformas e dispositivos.

Além disso, esse projeto será para leitura de múltiplas obras além de livros padrões.

## Tecnologias
Até o momento nesse projeto só está sendo usando as seguintes tecnologias:
- Java + Spring Boot
- MySQL
